# MRB Studio

MRB Studio 的固定访问入口与部署配置。

入口地址：https://zzh18877220541.github.io/mrb-studio/

GitHub Pages 提供固定入口和 HTTPS；完整工作台及其场景保存、资产标注、视频和网格服务运行在阿里云，通过带登录保护的 HTTPS 访问。

资产、人工标注、个人场景、示教数据及访问凭据不上传到此公共仓库。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/ (root)`。入口页面发布后由 GitHub Pages 自动更新。

部署验证尚在进行，入口上线状态以实际 HTTP 检查为准。
